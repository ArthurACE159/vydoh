ВЫДОХ 3.0 — первый релиз для проверки на Android

Установка/обновление GitHub Pages:
1. Перед обновлением экспортируйте резервную копию из установленного Выдоха.
2. Загрузите содержимое ЭТОЙ папки в корень репозитория vydoh (не сам ZIP и не дополнительную папку).
3. Убедитесь, что index.html, manifest.webmanifest, sw.js и папка icons находятся в корне.
4. Дождитесь завершения публикации GitHub Pages.
5. В установленном приложении нажмите «Проверить обновления». Когда появится «Применить обновление», нажмите её.
6. Проверьте счётчик, дневник, SOS и автономный режим. Не очищайте данные браузера.

Если обновление не предлагается сразу, полностью закройте приложение, откройте его снова и повторите проверку.
Данные хранятся локально для конкретного адреса сайта. Не меняйте адрес репозитория без экспорта/импорта.

ВАЖНО: на реальном Android версия 3.0 ещё не протестирована.
